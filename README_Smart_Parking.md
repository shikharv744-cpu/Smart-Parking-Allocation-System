# Smart Parking Allocation and Reservation Platform

DSA-II project combining:
- Unit 1: N-ary Tree, AVL Tree, Min-Heap
- Unit 2: Graph, BFS, DFS, Connected Components, Dijkstra, Bellman-Ford, Floyd-Warshall, Prim, Kruskal
- Unit 3: 0/1 Knapsack, LCS, Matrix Chain Multiplication, Resource Allocation

## Language
C

## Run
Compile `Smart_Parking_Complete_GitHub.c` using Code::Blocks, GCC, or another C compiler.
